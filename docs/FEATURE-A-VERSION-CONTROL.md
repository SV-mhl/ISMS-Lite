# Feature A — Version Control แบบ Controlled Document (Check-out / Check-in)

จัดการเวอร์ชันเอกสารที่ **เผยแพร่แล้ว** ด้วยการ check-out ออกมาปรับปรุง แล้ว check-in
กลับเป็นเวอร์ชันใหม่แบบเลขทศนิยม (1.x / 2.x) โดยเวอร์ชันที่เผยแพร่เดิมยังใช้งาน/ดาวน์โหลดได้
ระหว่างที่รุ่นใหม่ยังไม่อนุมัติ

## กติกา (ยืนยันโดยผู้ใช้ — ระดับ A1 เต็ม)
1. **Check-out ได้เฉพาะเอกสารสถานะ `เผยแพร่ (published)`** โดย **ผู้จัดทำ หรือ admin** → ล็อกเอกสาร (🔒 คนอื่นเห็น "กำลังแก้โดย X")
2. **Check-in เวอร์ชันใหม่** เลือกระดับ:
   - **แก้ไขย่อย (minor)** → เพิ่มเลขหลังจุด (เช่น 1.0 → **1.1**)
   - **แก้ไขใหญ่ (major)** → ขึ้นรุ่นถัดไป (เช่น 1.1 → **2.0**)
3. รุ่นใหม่เริ่มที่สถานะ **ร่าง** → ต้องเดิน workflow (ตรวจ → อนุมัติ → เผยแพร่) ใหม่
4. **Effective copy คู่ขนาน**: ระหว่างรุ่นใหม่ยังไม่เผยแพร่ เวอร์ชันเดิมที่เผยแพร่ (เช่น 1.0)
   **ยังดาวน์โหลดได้** · เมื่อรุ่นใหม่เผยแพร่ → กลายเป็น effective แทน (เดิมกลายเป็นประวัติ)
5. **timestamp ทุกเวอร์ชัน** (แสดงในหน้า `/documents/[id]` — ประวัติเวอร์ชัน + Timeline)

## โครงสร้างข้อมูล (migration 0003)
- `documents.effective_version_id` — เวอร์ชันที่เผยแพร่ล่าสุด (ใช้ดาวน์โหลด/เป็นฉบับจริง)
- `documents.checked_out_by` / `checked_out_at` — สถานะล็อก
- `document_versions.version_major` / `version_minor` — เลข label (1.0, 1.1, 2.0) · ของเดิม backfill = 1.0

## Flow / โค้ด (lib/documents.ts, lib/workflow.ts)
- `checkOut()` — ล็อก (published เท่านั้น)
- `cancelCheckOut()` — ปลดล็อกโดยไม่สร้างเวอร์ชัน
- `checkInRevision(bump)` — สร้างเวอร์ชันใหม่ (ร่าง) เลข minor/major, เคลียร์ล็อก, effective คงเดิม
- `addNewVersion()` — ใช้กับ draft/rejected (คง label เดิม) · **ถูกบล็อกถ้า published** (ต้อง check-out ก่อน)
- `publish()` — ตั้ง `effective_version_id` = เวอร์ชันที่เพิ่งเผยแพร่

## ดาวน์โหลด (lib/download.ts)
- `?v=effective` (ค่าเริ่มต้น) = ฉบับเผยแพร่ล่าสุด → ทุกคนโหลดได้ · ลายน้ำ "CONTROLLED COPY"
- `?v=working` = ฉบับร่างที่กำลังแก้ → เฉพาะผู้จัดทำ/ผู้ตรวจ/ผู้อนุมัติ/admin · ลายน้ำ "DRAFT"

## UI
- ตารางเอกสาร: label `v1.1`, ป้าย "กำลังแก้ไข", 🔒 lock + ชื่อผู้ถือ
- ปุ่ม: **เช็คเอาต์แก้ไข** / **เช็คอินเวอร์ชันใหม่** (modal เลือก minor–major + แนบไฟล์) / **ยกเลิก**
- "อัปเวอร์ชัน" (draft) แสดงเฉพาะเอกสารที่ยังไม่เผยแพร่
