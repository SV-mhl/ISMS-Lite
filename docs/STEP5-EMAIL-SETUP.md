# Step 5 — ตั้งค่าอีเมลแจ้งเตือน (Resend) — ทางเลือก

การแจ้งเตือน **ในแอป (🔔)** ทำงานทันทีโดยไม่ต้องตั้งค่าอะไร ส่วน **อีเมล** เป็นทางเลือก
ถ้ายังไม่ใส่ `RESEND_API_KEY` ระบบจะข้ามการส่งอีเมลอย่างสุภาพ (ไม่ error)

## เมื่อไรควรเปิดอีเมล
เมื่ออยากให้ผู้ตรวจ/ผู้อนุมัติได้รับเมลเตือนโดยไม่ต้องเปิดแอปค้างไว้

## ขั้นตอน (~10 นาที)
1. สมัคร/เข้าสู่ระบบ https://resend.com
2. **API Keys → Create API Key** → คัดลอกค่า (`re_...`)
3. **(แนะนำ) ยืนยันโดเมน** `maholan.co.th` ที่ **Domains → Add Domain** แล้วตั้ง DNS ตามที่ Resend บอก
   - ระหว่างยังไม่ยืนยันโดเมน ใช้ผู้ส่งทดสอบ `onboarding@resend.dev` ได้ (ส่งได้เฉพาะถึงอีเมลตัวเองที่ยืนยันในบัญชี Resend)
4. ใส่ใน `.env.local`:
   ```
   RESEND_API_KEY=re_xxxxxxxx
   EMAIL_FROM=ISMS-Lite <no-reply@maholan.co.th>   # ใช้โดเมนที่ยืนยันแล้ว
   ```
5. รีสตาร์ท `npm run dev`

## ทดสอบ
เดิน workflow (ส่งตรวจ/อนุมัติ/ตีกลับ/เผยแพร่) → ผู้ที่เกี่ยวข้องจะได้ทั้งการแจ้งเตือนในแอป 🔔 และอีเมล

## เหตุการณ์ที่ส่งแจ้งเตือน
| เหตุการณ์ | ผู้รับ |
|---|---|
| ส่งตรวจ | ผู้ตรวจ (reviewer) |
| ตรวจผ่าน | ผู้อนุมัติ (approver) + ผู้จัดทำ |
| อนุมัติ | ผู้จัดทำ |
| ตีกลับ | ผู้จัดทำ (พร้อมเหตุผล) |
| เผยแพร่ | ผู้จัดทำ + ผู้ตรวจ + ผู้อนุมัติ |

> หมายเหตุ: อีเมลเป็นแบบ best-effort — ถ้าส่งไม่สำเร็จจะไม่กระทบการทำงานของ workflow (log ไว้ที่ server เท่านั้น)
